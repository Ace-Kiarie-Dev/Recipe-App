# Mise — a pocket cookbook

An editorial-style recipe app built with vanilla HTML, CSS and JavaScript on top of the free [TheMealDB](https://www.themealdb.com) API. No build step — open `index.html` or deploy the folder as-is.

Live: https://recipe-app-a.netlify.app/

## Features

- **Search by dish** with live results — and if no dish matches, it falls back to recipes that use it as an ingredient.
- **What's in my fridge** — add ingredients as chips (with autocomplete) and meals are ranked by how many of them they use.
- **Chef's pick** — a random featured recipe on every visit, plus **Surprise me**.
- **Browse** by category or cuisine.
- **Recipe sheet** with tickable ingredients, a **servings scaler** (½× to 4×, fraction-aware), numbered steps, video and source links.
- **Tap-to-start timers** — any time in the method ("simmer for 20 minutes") becomes a button; timers run in a floating tray with an alarm.
- **Cook mode** — full-screen, one step at a time, keyboard/swipe navigation, shows the ingredients each step needs and keeps the screen awake.
- **Cookbook** — save favourites (stored on your device).
- **Shopping list** — add a recipe's (scaled) ingredients, tick them off, copy the list to paste anywhere.
- Shareable deep links (`#/meal/52772`), light/dark theme, keyboard shortcut `/` to search, responsive down to small phones.
